# Data

This project uses publicly available U.S. macroeconomic data from FRED.

The main variables include output, consumption, investment, capital, and other macroeconomic aggregates used for the RBC/DSGE analysis.

Raw data are not included in this repository. Users can download the original data from FRED and place them in the `data/raw/` folder.

Processed data, if included, should be stored in the `data/processed/` folder.
