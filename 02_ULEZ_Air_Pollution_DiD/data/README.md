# Data

This project uses UK air quality monitoring data from AURN/DEFRA to evaluate the August 2023 London ULEZ expansion.

The main outcome variable is NO₂ concentration measured at air quality monitoring stations.

Raw data are not included in this repository. Users should download the original data from the relevant public data source and place them in the `data/raw/` folder.

Processed station-day panel data, if included, should be stored in the `data/processed/` folder.
